# Инженерные примечания — ревизия D

Обозначения ниже — ревизии D (ГОСТ 2.710). Соответствие обозначениям ревизии C
приведено в `verification/refmap_revC_to_revD.json`. Например:

| Ревизия C | Ревизия D |
|---|---|
| U1 | D1 |
| U2 | D2 |
| J2 | XW1 |
| SW14 | S1 |

## 1. Состояние проекта

| Что | Состояние | Где проверить |
|---|---|---|
| Схема | 3 листа (DDS A2, Контроллер A3, Питание A2), ERC — 0 ошибок, 0 предупреждений | `reports/ERC.rpt` |
| Соединения | 160 компонентов, 139 цепей — совпадают с ревизией C. 12 одиночных DIP сгруппированы в корпуса S2 (8) и S3 (4) | `tools/netcompare.py` |
| Плата | 120×50 мм, 4 слоя: F.Cu / In1 = GND / In2 / B.Cu; монтаж односторонний | `DDS_47_51.kicad_pcb` |
| Разводка | все связи разведены. DRC со сверкой схемы: 0 нарушений, 0 неразведённых, 0 расхождений со схемой | `reports/DRC.rpt` |
| Производство | Gerber, Excellon, BOM/CPL для JLCPCB | `output/jlcpcb/README_JLC.md` |

**Схема и плата — инженерная ревизия, не выпуск в производство.** Пометка
«ЧЕРНОВИК» на Э3 остаётся, пока не закрыты пункты раздела 3.

## 2. Решения по плате

- **Стек — JLC04161H-7628, 1,6 мм, ENIG** (номинал изготовителя, параметры в
  `DDS_47_51.kicad_pcb` → Board Setup → Stackup):
  - F.Cu 35 мкм;
  - препрег 7628 — 0,2104 мм, εr 4,4;
  - In1 15 мкм;
  - ядро 1,065 мм;
  - In2 15 мкм;
  - препрег 0,2104 мм;
  - B.Cu 35 мкм.
- **Слой In1 — сплошная GND** без трасс. Все ВЧ-цепи идут по F.Cu над ней.
  - Пары и линии 480 МГц разведены вручную, зафиксированы (`tools/dds_pcb.py: clock_routes`)
    и не имеют переходных отверстий.
  - Для автотрассировщика классы CLK/CLK50 ограничены слоем F.Cu.
- **Внешний такт 480 МГц (XW1 → C3 → CLKDP)** — микрополосок 0,36 мм с копланарной
  землёй (зазор 0,2 мм). По Hammerstad–Jensen ≈ 50 Ом.
  - Нагрузка 49,9 Ом (R2) стоит у приёмника, рядом с C3, а не у разъёма.
  - Длина линии ≈ 24 мм.
- **LVDS-пара от G1 (CLKP/CLKM)** — 0,25/0,25 мм, по IPC-2141 ≈ 100–104 Ом.
  - Терминатор 100 Ом (R6) стоит в ≈ 5 мм от выводов 23/24 D1.
  - Разница длин ≈ 1,5 мм (≈ 9 пс при периоде 2,08 нс).
  - Группа G1 перенесена под угол D1, чтобы пара и линия внешнего такта не
    пересекались на одном слое.
- **Выход ЦАП1.** OUTM1 → R25 (нагрузка) и OUTP1 → R44 (шунт) → C5 → ФНЧ разведены
  на F.Cu без переходных отверстий.
- **Земля.**
  - Все выводы GND микросхем D1 и D2 выведены короткими стабами под корпус и
    переходными на In1.
  - У каждого развязывающего конденсатора — свой переходной на землю.
  - Земляные заливки на F.Cu, In2 и B.Cu сшиты переходными по сетке 2,5 мм там,
    где заливки всех слоёв совпадают.
- **Правила JLCPCB (4 слоя).**

  | Параметр | Значение |
  |---|---|
  | Дорожка / зазор | мин. 0,10/0,10 мм; по умолчанию 0,15/0,127 мм |
  | Переходные | 0,45/0,2 мм; питание 0,6/0,3 мм |
  | Поясок | ≥ 0,125 мм |
  | Медь – край платы | 0,3 мм |
  | ВЧ | 0,3/0,2 мм |
  | CLK | 0,25/0,2 мм |
  | CLK50 | 0,36/0,2 мм |

- **Шелкография.**
  - Обозначения крупных элементов — на F.Silkscreen.
  - Обозначения пассивных 0603/0805 — только на F.Fab (сборочный чертёж
    `output/pdf/DDS_47_51_pcb.pdf`, последняя страница, масштаб 2:1), иначе они
    не помещаются.
- **Посадочные места.**
  - 1508ПЛ8Т — IPC LQFP-100 14×14, шаг 0,5.
  - 1887ВЕ7Т — CQFP-64 (корпус 4203.64-2), шаг 0,8, площадки удлинены до 1,95 мм
    под формованные выводы.
  - Оба — по данным заказчика (раздел 3).

## 3. Открытые пункты (до выпуска)

1. **G1 ГК361-ТК-02 не подтверждён.** Посадочное место
   (`OSC_6pad_5.0x3.2mm_P1.27mm_GK361_UNVERIFIED`) и распиновка — заполнители,
   на схеме выводы помечены «?».
   - G1, R1 (EN), R3/R4 (0 Ом) не устанавливаются (DNP).
   - S1 замкнут: такт с XW1.
   - До установки нужно проверить по паспорту: корпус, распиновку, 480 МГц, LVDS,
     вывод EN, ток. Затем, если нужно, переложить посадочное место G1 и короткий
     участок пары до R3/R4.
2. **Чертежи корпусов D1 и D2 по ТУ** (АЕЯР.431320.596ТУ, АЕЯР.431280.910ТУ) не сверены.
   - Для 4203.64-2 проверить размах формованных выводов и длину площадок.
   - Маркер «PRELIM» на слое F.Fab.
3. **Импортные микросхемы** — TPS62161/2/3DSG (DC/DC), SN74LVC125A, SN74AHCT1G125.
   Вопрос замены на отечественные не решён.
4. **Отечественные аналоги пассивных элементов** не назначены. Кандидаты из образцов
   заказчика:

   | Элементы | Кандидат | ТУ |
   |---|---|---|
   | Резисторы | Р1-12 | ШКАБ.434110.021ТУ |
   | Конденсаторы керамические | К10-17в | ОЖ0.460.107ТУ |
   | Конденсаторы танталовые | К53-65 | АЖЯР.673546.004ТУ |

   Совместимость с посадочными местами 0603/0805/1206 проверить по ТУ. До этого
   в ПЭ3 стоят импортные типоразмеры.
5. **Импеданс.** Ширины 0,36 мм и 0,25/0,25 мм рассчитаны по формулам на номинальный
   стек. При заказе с контролем импеданса сверить их с калькулятором JLCPCB для
   JLC04161H-7628.
6. **Размер шрифта Э3** (1,27–1,8 мм) меньше, чем в образце (2,5 мм на A1). См.
   `docs/Правила_оформления_Э3_ПЭ3.md`, п. 2.3.
7. **Основные надписи.** Децимальный номер (`ХХХХ.ХХХХХХ.ХХХ`), фамилии
   разработчика и проверяющих, организация — нужны данные заказчика.
8. **ФНЧ 7-го порядка, fc ≈ 70 МГц.** Подавление 2-й гармоники (94–102 МГц) самим
   фильтром ≈ 18–23 дБ. Итоговый уровень гармоник проверить измерением на макете.

## 4. Примечания к прошивке и наладке (перенесены из ревизий B/C)

- **Тактирование.** CSEL = 1 (S1 замкнут) — внешний вход XW1: синус 480 МГц,
  0 дБм, 50 Ом, по переменному току. CSEL = 0 — G1 (CLKP/M); только после
  выполнения п. 3.1. Вход тактирования D1 имеет внутреннее смещение синфазного уровня.
- **Инициализация D1.**
  - DAC2 и компаратор выключить.
  - Выходы SYNC выключить.
  - LINK выключить, профиль 0.
  - Неиспользуемые выводы — резисторные подтяжки к земле.
  - Ток IFS = 10,07 мА (R11/R12 = 7,15 кОм, 0,1 %).
  - Размах на выходе без нагрузки ≤ 0,503 В (предел ±0,6 В).
- **Последовательность SPI.**
  - После включения D3 (SN74LVC125A) отключён.
  - Выставить CS = 1, SCK = 0, MOSI = 0, RESET = 0 и дождаться питания и такта.
  - Затем включить D3 и снять сброс D1.
  - SPI — 100 кГц, старшим битом вперёд, 24-битные команды.
  - Во время ISP D3 держать отключённым.
- **D2 1887ВЕ7Т (аналог ATmega128).**
  - Внутренний RC 8 МГц.
  - Проверить фьюз M103C (режим совместимости с ATmega103): он должен быть выключен.
  - ISP — через PE0/PE1. X1.2 — контроль напряжения цели; программатор не должен питать плату.
- **Задание частоты.** Положение ON = бит 1. N = Σ bit[i]·2^i, f = 47 000 000 + 1000·N Гц.
  - Допустимо N = 0…4000, значения 4001…4095 отвергать.
  - Кнопку «Применить» (S4) подавлять от дребезга, DIP читать дважды.
- **Питание.**
  - Вход +15 В ±5 %, VIN < 17 В. VD1 защищает от обратной полярности.
  - Ёмкости указаны эффективными при рабочем напряжении (X7R).
  - Выходы PG объединены по «И», МК проверяет напряжения после задержки.
  - Бюджет: 1,8 В ≤ 0,4 А (D1); 3,3 В ≤ 0,2 А для D1 плюс генератор.
- **ФНЧ — Баттерворт 7-го порядка, fc ≈ 70 МГц**, номиналы по E24.
  - Индуктивности ВЧ с Q ≥ 30 на 50 МГц; Q и SRF проверить по моделям изготовителя.
  - Уровень −10 дБм выставляется калиброванной амплитудой DDS.
  - SFDR и шумы не измерялись.

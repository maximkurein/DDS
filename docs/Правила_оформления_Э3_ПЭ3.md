# Правила оформления Э3 и ПЭ3 проекта DDS 47–51 МГц

Документ составлен по образцам заказчика (`obraz/Плата контроллера.vsd`,
`Плата контроллера.docx`, `Стенд диагностики Э3.vsd`, `Стенд диагностики ПЭ3.docx`)
и ГОСТ ЕСКД. Данные для обоих документов берутся только из проекта KiCad:
схема (`*.kicad_sch`) — единственный источник истины. Документы Visio и Word
демонстрационные и генерируются скриптами, руками не правятся.

| Документ | Источник | Генератор | Результат |
|---|---|---|---|
| Э3 (KiCad) | `DDS_47_51.kicad_sch` + 2 листа | `tools/dds_build.py` | `output/pdf/DDS_47_51_sch.pdf` |
| Э3 (Visio) | те же `.kicad_sch` + `lib/GOST_E3.kicad_wks` | `tools/sch2vsdx.py` | `output/visio/DDS_47_51_Э3.vsdx` |
| ПЭ3 (Word) | нетлист KiCad (`output/netlist/netlist.xml`) | `tools/pe3_docx.py` | `output/docs/DDS_47_51_ПЭ3.docx` |
| BOM | схема KiCad | `kicad-cli sch export bom` | `output/bom/BOM.csv` |

## 1. Общие требования (ГОСТ 2.104, 2.301, 2.304, 2.303)

1. Обозначение документа — `ХХХХ.ХХХХХХ.ХХХ Э3` / `… ПЭ3`. Это заполнитель:
   децимальный номер присваивается заказчиком.
2. Наименование изделия в основной надписи: «Синтезатор частоты 47–51 МГц»
   (Э3) и «Синтезатор DDS 47–51 МГц» (ПЭ3, укорочено, чтобы поместилось в одну строку графы 1).
3. Рамка: поле подшивки 20 мм слева, остальные поля 5 мм.
   - Первый лист — основная надпись по форме 1 (185×55 мм).
   - Последующие листы — форма 2а (185×15 мм).
   - Слева дополнительные графы: «Инв. № подл.», «Подп. и дата», «Взам. инв. №»,
     «Инв. № дубл.», «Подп. и дата».
   - На первом листе дополнительно «Справ. №» и «Перв. примен.».
   - В верхнем левом углу — обозначение документа, повёрнутое на 180°, как в образце.
4. Шрифт:
   - Э3 — Arial, как в образцах Visio.
   - ПЭ3 — Times New Roman 12 пт, как в образцах Word.
5. Графы «Разраб.», «Пров.», «Н.контр.», «Утв.» остаются пустыми, пока заказчик
   не сообщит фамилии.
6. Литера не проставляется. Причина: документ не согласован, на Э3 стоит пометка
   «ЧЕРНОВИК — не для производства».

## 2. Схема электрическая принципиальная (Э3)

### 2.1 Формат и компоновка

- Ровно три листа без титульного листа-оглавления:
  1. DDS — тракт синтеза и ФНЧ (A2);
  2. Контроллер, задатчик частоты, согласование уровней SPI (A3);
  3. Питание (A2).
- Сигнальный поток идёт слева направо: вход → обработка → выход. Цепи питания
  показываются символами питания (+5V, +3V3, +3V3_A, +1V8, +1V8_Q, +3V3_OSC, GND).
- Межлистовые связи — глобальные метки с именем цепи. На каждом листе метки
  одинаково называются и стоят у края группы.
- Сетка 1,27 мм. Все выводы и концы связей лежат на сетке.

### 2.2 Линии (ГОСТ 2.303, 2.721)

| Элемент | В образце | В проекте (Visio) |
|---|---|---|
| УГО и линии связи | 0,25 мм | 0,25 мм |
| Рамка, основная надпись — основные линии | 0,4–0,8 мм | 0,5 мм |
| Тонкие линии граф основной надписи | 0,25 мм | 0,25 мм |
| Точка соединения | Ø ≈ 1 мм | Ø 1 мм |

Пересечение четырёх линий в одной точке не допускается: используется Т-образное
соединение с точкой.

### 2.3 Размеры шрифта

Размеры текста из образца, по PDF-выгрузке листа A1:

| Текст | Образец | Проект (KiCad → Visio 1:1) |
|---|---|---|
| Имена выводов, имена цепей | 2,5 мм | 1,27 мм |
| Позиционные обозначения | 2,5–3,0 мм | 1,8 мм |
| Номиналы | 2,3–2,5 мм | 1,5 мм |
| Номера выводов | ≈ 0,85–1,0 мм | 1,0 мм |
| Обозначение документа в основной надписи | 4,5–5 мм | 5 мм |

Отступление от образца. Проект использует уменьшенный шрифт, чтобы схема
поместилась на три листа A2/A3: таково требование «компактная читаемая схема,
ровно три листа». Образец выполнен на A1. Чтобы перейти на 2,5 мм, нужно:

1. в `tools/gost_symbols.py` и `tools/sheet.py` увеличить размеры текста и ширину
   дополнительных полей УГО микросхем;
2. перейти на листы A1;
3. заново сгенерировать проект.

Это открытый пункт — см. `docs/design_notes.md`.

### 2.4 Условные графические обозначения

- **Микросхемы (ГОСТ 2.743).**
  - Прямоугольник с основным полем функции (DDS, MCU, RG, …).
  - Дополнительные поля меток выводов слева и справа.
  - Шаг выводов 5,08 мм. Номер вывода — над линией вывода.
  - Инверсия — кружок на выводе, а не черта над именем.
  - Многосекционная микросхема изображается частями `D1.1`, `D1.2` и т. д.
    Пример из образца: `D4.2`.
- **Пассивные элементы.**
  - Резистор — прямоугольник (ГОСТ 2.728).
  - Конденсатор — две пластины (ГОСТ 2.728).
  - Индуктивность — полуокружности (ГОСТ 2.723).
  - Ферритовый фильтр — индуктивность с сердечником.
- Диод Шоттки — по ГОСТ 2.730. Переключатели и кнопка — по ГОСТ 2.755.
- **Соединители.**
  - Вилки `X` — по ГОСТ 2.755.
  - Коаксиальные розетки `XW` — по ГОСТ 2.755: окружность с центральной точкой и выводом экрана.
- **Генератор G1 (ГК361-ТК-02).** Нумерация и функции выводов помечены «?», поле
  «НЕ ПОДТВЕРЖДЁН». Элемент не устанавливается (DNP), пока нет паспорта.

### 2.5 Позиционные обозначения (ГОСТ 2.710)

| Элементы | Код |
|---|---|
| Микросхемы (DDS, микроконтроллер, логика, DC/DC) | D |
| Конденсаторы | C |
| Резисторы | R |
| Индуктивности, дроссели, ферритовые фильтры | L |
| Диоды | VD |
| Генератор | G |
| Переключатели, кнопка | S |
| Вилки | X |
| Коаксиальные розетки | XW |
| Предохранитель | F |

Правила нумерации:

- Нумерация сквозная по изделию: слева направо, сверху вниз, лист за листом.
- Части многосекционных элементов обозначаются через точку: `D1.1`, `D1.2`.
  В проекте KiCad это задано настройками `subpart_id_separator = "."` и
  `subpart_first_id = "1"`.
- Секции сборок DIP-переключателей — `S2`, `S3` (по одному обозначению на корпус).

### 2.6 Надписи на поле схемы

- **Примечания.** Пронумерованный список в левом нижнем углу листа 1:
  - соединение земель;
  - расчёт тока IREF;
  - параметры ФНЧ;
  - перечень неподтверждённых узлов.
- **Таблица режимов CSEL.** Задаётся текстом рядом с S1:
  - замкнут — внешний такт с XW1;
  - разомкнут — генератор G1.
- Неподключённые выводы помечаются крестом (no-connect).

## 3. Перечень элементов (ПЭ3, ГОСТ 2.701)

1. Формат A4.
   - Первый лист — форма 1, основная надпись 40 мм.
   - Последующие листы — форма 2а.
   - Последний лист — «Лист регистрации изменений».
   - Шаблон — `obraz/Плата контроллера.docx`.
2. Графы таблицы:

   | Графа | Ширина, мм |
   |---|---|
   | Зона | 8,4 |
   | Поз. обозначение | 21 |
   | Наименование | 115 |
   | Кол. | 10,5 |
   | Примечание | 27 |

   Шапка повторяется на каждом листе. Строка — Times New Roman 12 пт, интервал 1,5.
3. Порядок записи.
   - Элементы группируются по буквенному коду в порядке латинского алфавита:
     C, D, F, G, L, R, S, VD, X, XW.
   - Внутри группы — по возрастанию номера.
4. Заголовок группы (`Конденсаторы`, `Микросхемы`, `Индуктивности`, `Резисторы`, …)
   пишется по центру графы «Наименование». Между группами — одна пустая строка.
5. Одиночный элемент записывается без заголовка, полным наименованием:
   «Предохранитель …», «Диод Шоттки …».
6. Одинаковые элементы с подряд идущими номерами объединяются в одну строку:
   - три и более — диапазоном `C3–C5`;
   - два — через запятую `R3, R4`.
7. Наименование.
   - **Отечественные изделия** — тип и обозначение ТУ:
     - `1508ПЛ8Т АЕЯР.431320.596ТУ`;
     - `1887ВЕ7Т АЕЯР.431280.910ТУ`.
   - **Импортные пассивные элементы** — типоразмер, параметры, номинал, допуск:
     - `0603 – 0,063 Вт – 10 кОм ±5%`;
     - `0603 – X7R – 50 В – 0,1 мкФ`.
   - **Импортные микросхемы** — полный код заказа и изготовитель.
8. Примечание.
   - Невыставляемые элементы — «Не устанавл.».
   - Для G1 — «Не устанавл. Не подтвержд.».
   - Размер шрифта графы 10 пт, как «Допускаемая замена» в образце.
9. Количество строк и элементов ПЭ3 сверяется с нетлистом автоматически.
   `pe3_docx.py` завершается ошибкой, если сумма графы «Кол.» не равна числу
   компонентов схемы.
10. Отечественные аналоги пассивных элементов в ПЭ3 не записываются, пока не
    проверена совместимость посадочных мест по ТУ. Кандидаты из образцов:
    - резисторы Р1-12 (ШКАБ.434110.021ТУ);
    - конденсаторы К10-17в (ОЖ0.460.107ТУ);
    - танталовые К53-65 (АЖЯР.673546.004ТУ).

    Они перечислены в `docs/design_notes.md` как открытый пункт.

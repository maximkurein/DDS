# Заказ печатных плат в JLCPCB — DDS 47–51 МГц, ревизия D

Все файлы этой папки сгенерированы из `DDS_47_51.kicad_pcb` скриптом
`tools/make_outputs.sh`. Руками их не правят: при изменении платы папку надо
пересобрать.

| Файл | Назначение |
|---|---|
| `DDS_47_51_gerber.zip` | загружается в JLCPCB: 11 слоёв Gerber, сверловка PTH/NPTH (Excellon, мм), job-файл |
| `gerber/` | те же файлы распакованные, плюс карты сверловки (`*-drl_map.gbr`, только для просмотра) |
| `BOM_JLC.csv` | BOM в формате JLCPCB (без DNP), графа LCSC пустая |
| `CPL_JLC.csv` | координаты установки (без DNP), абсолютные координаты KiCad |
| `pos_kicad.csv` | исходный файл позиций KiCad |

## Параметры заказа

| Параметр | Значение |
|---|---|
| Layers | 4 |
| Dimensions | 120 × 50 мм |
| PCB Thickness | 1.6 mm |
| Layer stackup | JLC04161H-7628 (L1 – препрег 0,21 мм – L2 = GND) |
| Surface Finish | ENIG (обязательно: шаг выводов 0,5 мм у D1 и 0,8 мм у D2) |
| Outer / inner copper | 1 oz / 0.5 oz |
| Min track / spacing | 0.10 / 0.10 мм (4/4 mil); фактически 0,15 / 0,127 мм |
| Min via | 0,2 / 0,45 мм (отверстие / площадка); проверить, не добавляет ли эта опция стоимость |
| Via covering | Tented |
| Impedance control | по желанию: LVDS 100 Ом и 50 Ом — на L1 над L2. Ширины 0,25/0,25 мм и 0,36 мм рассчитаны по формулам — сверить с калькулятором JLC |
| Mark on PCB / Remove order number | метка «JLCJLCJLCJLC» на шелкографии не размещена. Номер заказа убрать опцией «Remove» (обычно за небольшую доплату) или согласиться на номер в произвольном месте |
| Silkscreen / color | белая / зелёная |
| Stencil | рекомендуется (LQFP-100 с шагом 0,5): толщина 0,12 мм, верхняя сторона |

Цену и срок смотреть в калькуляторе JLCPCB на момент заказа.

## Сборка

Монтаж JLCPCB (PCBA) для этой ревизии не рекомендуется:

- D1 1508ПЛ8Т и D2 1887ВЕ7Т на складе LCSC отсутствуют;
- DIP-переключатели, кнопка, вилки и SMA-разъёмы — выводные или торцевые.

Рекомендуемый путь — заказать платы и трафарет, монтировать самостоятельно.

Если пассивные элементы и микросхемы TI нужно смонтировать в JLCPCB:

1. Заполнить графу `JLCPCB Part #` в `BOM_JLC.csv` кодами LCSC.
2. Исключить строки D1, D2, S1–S4, X1, X2, XW1, XW2.
3. Проверить в просмотрщике JLCPCB поворот поляризованных компонентов (CPL —
   углы KiCad): VD1, D3–D7, кнопка, DIP.

Не устанавливаются (DNP): G1 (ГК361-ТК-02 не подтверждён), R1, R3, R4.

## Проверки перед отправкой

- В просмотрщике Gerber у JLCPCB проверить порядок слоёв: L1 = `F_Cu.gtl`,
  L2 = `In1_Cu.g1` (сплошная GND), L3 = `In2_Cu.g2`, L4 = `B_Cu.gbl`.
- Контур — `Edge_Cuts.gm1`, 120×50 мм, углы R1.
- DRC KiCad перед выгрузкой: 0 нарушений, 0 неразведённых (`reports/DRC.rpt`).

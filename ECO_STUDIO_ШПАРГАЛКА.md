# Шпаргалка: «Ревизии платы» (PCB ECO Studio)

Интерактивный справочник по исправлению платы DDS 48–52 в KiCad: что меняем → маршрут правки, зона перестройки, ворота и команды, кто что делает.
Логика целиком взята из навыков `.claude/skills/pcb-revision-eco` и `pcb-design-pipeline` — страница их наглядное отображение, а не отдельные правила.

## Где эта страница живёт

| Где | Что это | Как открыть |
|---|---|---|
| `studio/public/eco/index.html` | **Главный файл** (в git, работает без сети) | двойной клик → откроется в браузере на Windows и macOS |
| DDS Studio → «Практика» → **Ревизии платы** | тот же файл внутри приложения | `.exe`/`.msi` или `.dmg` после сборки |
| claude.ai → артефакт «PCB ECO Studio — DDS» | веб-копия, видна только владельцу, можно поделиться ссылкой | ярлык на рабочем столе / ссылка из чата |

Ярлык «PCB ECO Studio — DDS – Claude artifact» на рабочем столе — это ссылка на веб-копию на claude.ai, не файл программы. Открывается при входе в аккаунт Claude.

Веб-копия **не обновляется сама**: после правки `studio/public/eco/index.html` попросите Claude перепубликовать артефакт.

## macOS

```bash
cd ~/Project/DDS && git pull
```

## Как пользоваться

1. **Мастер изменения** — выбрать сценарий («Заменить L8 дросселем в другом корпусе») или тип T1–T8, режим проекта и Konnect.
2. Смотреть: цепочку «База ЭРИ → … → Документы» (жёлтое — точечно, красное — целиком), предупреждения, шаги с исполнителем, команды ворот (кнопка «Копировать»), что изменится в КД.
3. Писать Claude: «замени L8 на <тип>, вот даташит» — он идёт тем же маршрутом.

| Тип | Что | Разводка |
|---|---|---|
| T1 | номинал, допуск, примечание | нет |
| T2 | замена, тот же корпус и выводы | нет (F8) |
| T3 | замена, другой корпус | локально: цепи элемента |
| T4 | соединения: элементы, цепи | локально |
| T5 | контур, отверстия, разъёмы | да |
| T6 | шелкография, обозначения | нет |
| T7 | только текст документов | нет |
| T8 | стек, покрытие, заказ | иногда |

Режимы: **генератор** (`build_all.sh`/`route_all.sh` перестраивают всё) · **ручная доработка** (генераторы не запускать, правки точечно: KiCad, Konnect, `ripnet`/`minirouter`) · **неизвестен** (стоп, определить по `git log`).
Ворота: ERC 0 · сверка (а) и (б) IDENTICAL · DRC `--schematic-parity` 0/0/0 · затем `sh tools/make_outputs.sh .` — комплект КД только оттуда, не из экспорта Konnect.

## Как сделано и почему выглядит аккуратно

**Один файл HTML без фреймворков**: стили, данные и логика внутри `index.html` (~36 КБ). Ничего не грузится из сети — работает в браузере, в Tauri и офлайн.

**Данные отдельно от отрисовки** (блок `<script>` в конце файла):

| Таблица | Что в ней |
|---|---|
| `T` | типы T1–T8 и строка матрицы влияния по 7 звеньям цепочки |
| `PRESETS` | готовые сценарии: название, тип, режим |
| `CMD` | команды ворот с пояснением |
| `GATES` | какие команды нужны каждому типу |
| `DOCS` | что меняется в документах для каждого типа |
| `PHASES`, `PITS` | фазы 0–9 с воротами; грабли «симптом → причина → что делать» |

`steps()` строит маршрут из типа, режима и флага Konnect; `alerts()` — предупреждения; `render()` перерисовывает правую панель при каждом клике. Разделы переключаются по `#hash` (`#wizard`, `#matrix`, …) — ссылку на раздел можно отправить.

**Оформление**:
- палитра и токены — из `studio/src/index.css` (DDS Studio), поэтому страница выглядит частью приложения;
- цвет несёт смысл, а не украшает: фиолетовый — вы в KiCad, зелёный — Claude, бирюзовый — Konnect, жёлтый — затронуто правкой, красный — стоп/перестройка целиком; легенда в боковой панели;
- один акцентный цвет для выбранного, одинаковые радиусы и отступы у карточек, моноширинный шрифт для кодов и команд;
- светлая и тёмная тема: токены в `:root`, переопределения в `prefers-color-scheme` и `[data-theme="dark"]` — внутри студии тема передаётся из приложения;
- адаптивность: на узком экране колонки складываются в одну.

**Встраивание в DDS Studio**: `studio/public/` Vite копирует в `dist/` как есть → `src/views/EcoView.tsx` показывает `eco/index.html` во встроенном фрейме и ставит ему тему → пункт «Ревизии платы» в `Sidebar.tsx` (`NAV`), вид в `App.tsx` (`VIEWS`), id `"eco"` в `ViewId` (`src/lib/types.ts`). Tauri упаковывает `dist/` в `.exe`/`.msi`/`.dmg`.

## Как дорабатывать

- **Новый сценарий** — строка в `PRESETS`: `["Заменить C12 на 22 мкФ 1210","T3","manual"]`.
- **Новая команда ворот** — ключ в `CMD` и его имя в нужных строках `GATES`.
- **Новые грабли** — строка в `PITS`.
- Меняется процесс — сначала правка в навыке (`.claude/skills/...`), потом в этих таблицах, чтобы страница и навык говорили одно и то же.
- Проверка: открыть файл в браузере, пройти мастер; в студии — `npm run build` (tsc + vite).
- Выпуск студии: `cd studio && python tools/update_version.py bump minor` (или из корня `python tools/update_version.py studio bump minor`), запись в `studio/CHANGELOG.md`, сборка, push в `origin` и `nas`.
- Версии всего проекта (плата, прошивка, студия) — [VERSION_MANAGEMENT.md](VERSION_MANAGEMENT.md).

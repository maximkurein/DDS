# DDS 47–51 МГц — ревизия E (инженерная версия)

Синтезатор частоты 47–51 МГц с шагом 1 кГц, выход −10 дБм на 50 Ом.

| Узел | Что |
|---|---|
| DDS | 1508ПЛ8Т (D1) |
| Контроллер | 1887ВЕ7Т (D2) |
| Питание | +15 В → DC/DC 1393ЕУ014 (+5 В) → LDO 1158ЕН3.3ВХ (+3,3 В), 1325ЕН1.8У (+1,8 В) |
| Плата | 120×50 мм, 4 слоя |
| Задание частоты | 12 DIP-переключателей (S2 — 8 разрядов, S3 — 4 разряда) |
| Загрузка значения | кнопка «Применить» (S4) |
| Источник такта | выбирается S1: внешний вход XW1 или генератор G1 |

**Ревизия E.** Импортные стабилизаторы и логика заменены отечественными:
DC/DC 1393ЕУ014 + LDO 1158ЕН3.3ВХ и 1325ЕН1.8У вместо TPS62161/2/3,
1564АП3У2 и 1594ТЛ2Т вместо SN74LVC125A и SN74AHCT1G125.

**Статус.**

- ERC — 0;
- соединения совпадают с заданными изменениями ревизии E, а для незатронутых
  узлов — с ревизией C;
- DRC со сверкой со схемой — 0 (плата разведена на посадочных местах-заполнителях).

Это **не выпуск в производство**:

- посадочные места новых отечественных элементов (1393ЕУ014, 1158ЕН3.3ВХ,
  1325ЕН1.8У, 1564АП3У2, 1594ТЛ2Т, 2Д2990А, ИД1-56, К53-65) — заполнители до
  получения чертежей корпусов;
- генератор ГК361-ТК-02 (G1) не подтверждён паспортом и не устанавливается;
- чертежи корпусов D1/D2 по ТУ не сверены;
- нагрев 1325ЕН1.8У (до 1,3 Вт) и устойчивость 1393ЕУ014 нужно проверить.

Открытые пункты — в [docs/design_notes.md](docs/design_notes.md), раздел 4.

## Как открыть

Открыть `DDS_47_51.kicad_pro` в KiCad 10.0. Проект сделан в KiCad 10.0.6.

| Лист | Файл | Формат | Содержание |
|---|---|---|---|
| 1. DDS | `DDS_47_51.kicad_sch` | A2 | 1508ПЛ8Т, тактирование 480 МГц, нагрузки ЦАП, ФНЧ, аттенюатор, развязка питания DDS |
| 2. Контроллер | `02_controller.kicad_sch` | A2 | 1887ВЕ7Т, ISP, DIP-переключатели, «Применить», согласование уровней SPI (1564АП3У2, 1594ТЛ2Т) |
| 3. Питание | `03_power.kicad_sch` | A3 | вход +15 В, защита, DC/DC +5 В (1393ЕУ014), LDO +3,3 / +1,8 В |

Оформление ГОСТ — прямо в KiCad:

- позиционные обозначения по ГОСТ 2.710 (`D1.1`, `XW1`, `S2`…);
- УГО по ГОСТ 2.743;
- рамка и основная надпись по формам 1 и 2а (`lib/GOST_E3.kicad_wks`).

Библиотеки проекта лежат в `lib/` и подключаются через `${KIPRJMOD}`.

## Как пересобрать

Нужно:

- KiCad 10 (`kicad-cli` и модуль `pcbnew` в его Python);
- Java 21+ и Freerouting 2.5 (переменная `FREEROUTING_JAR`);
- Python-пакеты `shapely`, `vsdx`, `python-docx`, `pillow`.

```sh
tools/build_all.sh .            # схема + расстановка; добавить "route" — полная разводка
tools/route_all.sh .            # только разводка платы (Freerouting + доводка + DRC)
tools/make_outputs.sh .         # PDF, BOM, нетлист, ERC/DRC, Gerber/BOM/CPL JLC, Visio Э3, Word ПЭ3
```

Скрипты из `tools/`:

| Скрипт | Назначение |
|---|---|
| `dds_build.py` | генератор схемы |
| `gost_symbols.py`, `gost_wks.py`, `kisch.py`, `sheet.py` | его модули |
| `dds_parts.py` | база компонентов |
| `eco.py` | изменения соединений ревизии E (отечественные стабилизаторы и логика) |
| `make_footprints.py` | посадочные места проекта |
| `dds_pcb.py` | расстановка, правила, зафиксированные ВЧ-трассы, вызов Freerouting |
| `minirouter.py` | доводочный трассировщик |
| `zero_len.py`, `drc_fix.py`, `silk_place.py` | чистка и шелкография |
| `pcb_meta.py` | стек и штамп платы |
| `netcompare.py` | сверка соединений: с заданным нетлистом ревизии E и с ревизией C |
| `sch2vsdx.py` | Э3 → Visio |
| `pe3_docx.py` | ПЭ3 → Word по форме `tools/templates/ПЭ3_форма_А4.docx` |
| `jlc_bom_cpl.py` | BOM/CPL для JLCPCB |

Ручные правки в KiCad допустимы. Но после них нельзя снова запускать
`build_all.sh` / `route_all.sh`: генераторы перезапишут схему и плату.
Документы (`make_outputs.sh`) пересобираются из текущих файлов KiCad и правки не затирают.

## Работа на Windows и macOS

Проект ведётся параллельно на Windows и Mac через GitHub.

- Концы строк задаёт `.gitattributes`: все текстовые файлы хранятся и
  выгружаются с LF на любой ОС, настройка `core.autocrlf` на это не влияет.
  CSV для JLCPCB хранятся как есть (CRLF).
- Пути к KiCad скрипты `tools/*.sh` берут из `tools/env.sh` — он сам находит
  KiCad на macOS (`/Applications/KiCad/KiCad.app`), Windows
  (`C:\Program Files\KiCad\<версия>`) и Linux. Любой путь можно переопределить
  переменными `KICAD_CLI`, `KPY` (Python с модулем `pcbnew`), `KICAD_FP`,
  `FREEROUTING_JAR`.
- На Windows скрипты запускаются из Git Bash: `sh tools/make_outputs.sh .`
- Python-пакеты ставятся в Python KiCad:
  - macOS: `/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3 -m pip install shapely vsdx python-docx pillow`
  - Windows: `"C:\Program Files\KiCad\10.0\bin\python.exe" -m pip install shapely vsdx python-docx pillow`
- Локальные настройки KiCad (`*.kicad_prl`), бэкапы и lock-файлы в git не идут.
- Порядок: перед работой `git pull`, после — `git commit` и `git push`.
  Файлы `.kicad_sch` / `.kicad_pcb` при конфликте вручную не сливаются,
  поэтому одну и ту же схему или плату не правьте на двух машинах одновременно.

# DDS 47–51 МГц — ревизия C (рабочая версия, черновик)

Синтезатор частоты 47–51 МГц с шагом 1 кГц и выходом −10 дБм на 50 Ом.
DDS 1508ПЛ8Т, контроллер 1887ВЕ7Т, питание +15 В, плата не более 80×50 мм.
Частота задаётся 12 DIP-переключателями, кнопка «Применить» загружает значение.

**Статус: инженерный черновик, к производству не готов.** ERC не чистый,
посадочные места не назначены, печатной платы ещё нет, генератор
ГК361-ТК-02 (480 МГц) паспортом не подтверждён — его параметры и распиновка
не считаются проверенными.

## Как открыть

Открыть `DDS_47_51.kicad_pro` в KiCad 10.0. Схема — ровно три листа,
без листа-оглавления:

| Лист | Файл | Формат | Содержание |
|---|---|---|---|
| 1. DDS | `DDS_47_51.kicad_sch` | A2 | 1508ПЛ8Т, тактирование, нагрузки ЦАП, ФНЧ и аттенюатор, подтяжки, фильтрация и развязка питания DDS |
| 2. Контроллер | `02_controller.kicad_sch` | A2 | 1887ВЕ7Т, ISP, 12 переключателей, «Применить», согласование уровней SPI |
| 3. Питание | `03_power.kicad_sch` | A3 | вход +15 В, защита, преобразователи +5 / +3,3 / +1,8 В |

Листы 2 и 3 открываются из дерева иерархии или по рамкам внизу листа 1.

## Структура папки

| Путь | Что лежит |
|---|---|
| `*.kicad_pro`, `*.kicad_sch` | исходники проекта KiCad (редактируемые) |
| `docs/` | инженерные примечания (`design_notes.md`), правила оформления |
| `output/pdf/` | актуальный PDF схемы |
| `output/bom/` | перечень элементов из KiCad (CSV) |
| `output/netlist/` | netlist (XML-экспорт KiCad) |
| `reports/` | отчёты ERC/DRC |
| `verification/` | эталоны для сверки соединений (`expected_connections.json`) |
| `tools/` | скрипты; `tools/legacy/` — генераторы ревизий B/C от предыдущего этапа |

Папка `obraz/` — образцы оформления (Э3 в Visio, ПЭ3 в Word); в git не отслеживается.

## История

- Ревизия B — 10 листов (оглавление + 9). Сохранена в git: метка `revB-baseline`.
- Ревизия C — перекомпоновка той же схемы на три листа без изменения соединений
  (170 компонентов, 139 цепей совпадают с ревизией B по netlist).

ERC ревизии C на момент переноса (`reports/ERC.rpt`, KiCad 10.99): 849 замечаний —
671 о сетке соединений, 170 о библиотечных символах, 8 о недрайвленных входах
питания. Исправление ведётся в этой рабочей версии.

# DDS 47–51 МГц — ревизия B

## Как открыть схемы

Откройте `DDS_47_51.kicad_pro` в KiCad. Корневой лист `DDS_47_51.kicad_sch` служит оглавлением и содержит рамки девяти иерархических листов. Поэтому на нём много пустого места — элементы схем находятся в отдельных файлах ниже. В KiCad откройте нужный лист из дерева иерархии или дважды щёлкните его рамку.

| Лист | Содержимое |
|---|---|
| `01_power.kicad_sch` | Вход +15 В и формирование питающих напряжений |
| `02_dds.kicad_sch` | 1508ПЛ8Т, распиновка и токовые установки |
| `03_bias.kicad_sch` | Фиксация неиспользуемых входов и фильтрация питания |
| `04_bypass.kicad_sch` | Локальные конденсаторы развязки |
| `05_mcu.kicad_sch` | Контроллер 1887ВЕ7Т |
| `06_ui.kicad_sch` | DIP-переключатели и кнопка APPLY |
| `07_spi.kicad_sch` | SPI и согласование уровней 5 В / 3,3 В |
| `08_clock.kicad_sch` | Тактовый источник и входной тракт |
| `09_rf.kicad_sch` | Выходной тракт, ФНЧ и 50-омный выход |

## Состав проекта

- `DDS_47_51.pdf` — экспорт всех десяти листов.
- `BOM.csv` — перечень компонентов.
- `netlist.xml` и `expected_connections.json` — соединения и ожидаемые связи.
- `ERC.rpt` — сохранённый отчёт электрической проверки; в нём остаются ошибки и предупреждения.
- Папка `revA_archive` хранит прежнюю ревизию A и её генератор.

## Статус

Это инженерный черновик, не готовый комплект для изготовления. Параметры G1 нужно подтвердить по паспорту конкретного генератора. Не завершены проверка посадочных мест, разводка платы, тепловая и шумовая оценка, а также измерения и калибровка ВЧ-выхода. Переносимое содержимое сохраняет исходный статус Rev B; наличие PDF и netlist само по себе не означает, что схема прошла окончательную проверку.

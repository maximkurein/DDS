Файлы описания микроконтроллера 1887ВЕ7Т (xml-файлы) необходимо скопировать в соответсвующие разделы установленной программной среды.

1) Для AVR Studio 4 необходимо файл 1887bBE7Т.xml скопировать в папку Partdescriptionfiles,
   которая по умолчанию находится по следующему пути:
   
      c:\Program Files\Atmel\AVR Tools\Partdescriptionfiles\

2) Для Atmel Studio 6 необходимо файл описания скопировать в папку Device, которая по умолчанию находится по следующему пути:

      c:\Program Files\Atmel\Atmel Studio 6.2\devices\
   
   также необходимо скопировать в папку tools соотвествующие файлы для различных поддерживаемых отладочных средств, которая по умолчанию находится по следующему пути:

      c:\Program Files\Atmel\Atmel Studio 6.2\tools\

Все! Теперь микроконтроллер 1887ВЕ7Т поддерживается инструментами программирования STK500, STK600, JTAGICE mkII, JTAGICE3, AVRISP mkII.

При создании проекта выбираем ATmega128!
При программировании выбираем 1887ВЕ7Т!

Успеха!

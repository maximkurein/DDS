# Фазы 7–8: документы и выдача в производство

Все документы получаются одной командой из текущих файлов KiCad и **не затирают ручные правки платы и схемы**:

```sh
sh tools/make_outputs.sh .        # на Windows — из Git Bash
```

## Что получается и откуда

| Результат | Источник | Генератор |
|---|---|---|
| `output/netlist/netlist.xml` | схема | `kicad-cli sch export netlist --format kicadxml` |
| `output/pdf/*_sch.pdf` (Э3) | схема | `kicad-cli sch export pdf` |
| `output/bom/BOM.csv` | схема | `kicad-cli sch export bom` (поля: Допуск, Мощность, Напряжение, ТКЕ, Примечание, Кол., DNP) |
| `reports/ERC.rpt`, `reports/DRC.rpt` | схема, плата | `kicad-cli sch erc`, `pcb drc --schematic-parity` |
| `output/pdf/*_pcb.pdf` | плата | `kicad-cli pcb export pdf`, слои, масштаб 2:1, последняя страница — сборочный чертёж (F.Fab) |
| `output/jlcpcb/*_gerber.zip` | плата | `pcb export gerbers` + `pcb export drill` (Excellon, мм), без карт сверловки |
| `output/jlcpcb/BOM_JLC.csv`, `CPL_JLC.csv` | нетлист + `pos_kicad.csv` | `jlc_bom_cpl.py` (без DNP) |
| `output/jlcpcb/ORDER_RU.txt`, `ORDER_EN.txt` | плата + `docs/order_params.json` | `order_txt.py` (текст запроса посреднику/заводу на только платы; количество — `ORDER_QTY=10 sh tools/make_outputs.sh .`) |
| `output/visio/*_Э3.vsdx` | `.kicad_sch` + рамка | `sch2vsdx.py` |
| `output/docs/*_ПЭ3.docx` | нетлист + шаблон Word | `pe3_docx.py` |

Правило: Visio и Word — «демонстрационные копии». Данные в них берутся только из KiCad; если нужно изменить текст в ПЭ3 — меняется поле компонента в базе
(`note`, `value`, …) и документ пересобирается. Ручная правка `.docx` / `.vsdx` пропадёт при следующей сборке.

## Перечень элементов (ПЭ3): что важно знать

- Группировка по буквенному коду в латинском порядке (C, D, F, G, L, R, S, VD, X, XW); внутри — по номеру.
- Одинаковые подряд: три и более — диапазоном `C3–C5`, два — через запятую `R3, R4`. Одиночный — без заголовка группы.
- Отечественные: тип + обозначение ТУ. Импортные пассивные: типоразмер, параметры, номинал, допуск. Импортные микросхемы: код заказа и изготовитель.
- Примечание: «Не устанавл.» для DNP, «Не устанавл. Не подтвержд.» для G1.
- `pe3_docx.py` завершается ошибкой, если сумма графы «Кол.» не равна числу компонентов схемы — не обходи её, найди причину в нетлисте.
- Шаблон формы — `tools/templates/ПЭ3_форма_А4.docx` (получен из образца заказчика командой `--make-template`).

## Заказ в JLCPCB (`output/jlcpcb/README_JLC.md`)

README пересобирается вместе с ревизией: параметры заказа (слои, размер, стек, финиш, трафарет), список не устанавливаемых элементов, что монтировать самому.
Правила, оправдавшиеся в DDS:

- ENIG обязателен при шаге выводов 0,5 мм; трафарет рекомендуется.
- Отечественных микросхем на складе LCSC нет → заказ «плата + трафарет», монтаж самостоятельно.
- Перед отправкой проверить поворот полярных элементов в просмотрщике JLCPCB (углы CPL — углы KiCad).
- Если плата содержит заполнители посадочных мест — в README явная пометка «не для заказа в производство», Gerber годится только для оценки компоновки.

## Запрос на изготовление плат (ORDER_RU.txt / ORDER_EN.txt)

Генерируются, руками не правятся. Размер, число слоёв и толщина берутся из платы; остальное (стек, покрытие, медь, цвет, импеданс, трафарет, контакт) —
из `docs/order_params.json`. Количество задаётся при сборке: `ORDER_QTY=10 sh tools/make_outputs.sh .`. Пока `production_ready` = false, сверху стоит
пометка «не для производства» — снимай её (`true`) только когда открытые пункты закрыты. Контакт — персональные данные: передавай через `ORDER_CONTACT="Имя, телефон"` при сборке, в `order_params.json` не пиши и файлы с реальным контактом не коммить. Отправляется вместе с `*_gerber.zip`.
Для нового заказчика/посредника меняй `docs/order_params.json` и при необходимости вопросы в `order_txt.py` (раздел «Вопросы»).

(см. коммит `c3f2801`). Реальные изменения проверяй по `netlist.xml`, `BOM.csv`, `ERC.rpt` и `DRC.rpt`.

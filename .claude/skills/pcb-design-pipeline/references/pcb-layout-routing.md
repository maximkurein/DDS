# Фазы 5–6: плата — контур, стек, правила, расстановка, разводка

Всё выполняется в Python KiCad (`$KPY`, модуль `pcbnew`) — пути берутся из `tools/env.sh`.

## 5. Контур, стек, правила

- **Стек** выбирай под изготовителя заранее. В DDS: JLC04161H-7628, 1,6 мм, ENIG; F.Cu 35 мкм / препрег 0,2104 мм / In1 15 мкм / ядро 1,065 мм / In2 15 мкм / препрег / B.Cu 35 мкм.
  Записывается в `.kicad_pcb` скриптом `pcb_meta.py` (идемпотентно), вместе с основной надписью платы.
  Значения — номинальные от изготовителя; перед заказом с контролем импеданса сверить с калькулятором изготовителя.
- **Слой In1 — сплошная земля**, без трасс. ВЧ-цепи идут по внешнему слою над ней, без переходных.
- **Правила** (JLCPCB, 4 слоя): дорожка/зазор по умолчанию 0,15/0,127 мм (минимум изготовителя 0,10/0,10), переходные 0,45/0,2 мм
  (питание 0,6/0,3), поясок ≥ 0,125 мм, медь от края 0,3 мм. Классы цепей: ВЧ 0,3/0,2; CLK 0,25/0,2; CLK50 0,36/0,2.
  Правила применяет `apply_rules` в `dds_pcb.py` и сохраняет в `.kicad_pro`.
- **Импеданс:** ширины считаются по формулам (Hammerstad–Jensen для микрополоска, IPC-2141 для дифпары) на номинальный стек.
  Записывай расчёт в `design_notes.md` — иначе при смене стека (ревизия) его нечем пересчитать.

## Расстановка

`dds_pcb.py place` расставляет компоненты по правилам, зашитым в `place_all`:

- микросхема-центр, вокруг неё «кольца» развязывающих конденсаторов (`ring`): конденсатор рядом с выводом питания, свой переходной на землю у каждого;
- ВЧ-узлы — по ходу сигнала, терминаторы у приёмника (не у разъёма);
- узел питания: входные конденсаторы под выводами VIN, дроссель и диод у выводов SW, делитель ОС у FB/SS; импульсная петля Cвх → VIN → SW → диод → GND — минимальной площади;
- тепловыделяющие элементы — с полигонами теплоотвода (`heat_zones`) и сшивкой переходными;
- односторонний монтаж (всё на F.Cu), если не оговорено иное.

Для нового изделия `place_all` пишется заново; берётся структура: вспомогательные функции (`put`, `ring`, `pad_xy`) универсальны.

## 6. Разводка

Порядок слоёв работы в `route_all.sh`:

1. `dds_pcb.py route` — ВЧ-трассы заранее и зафиксированы (`clock_routes`, `dac_routes`), затем Freerouting для остальных цепей.
   Для ВЧ-классов автотрассировщик ограничен слоем F.Cu (`restrict_layers`).
2. `minirouter.py` — доводка оставшихся неразведённых пар: прямая на F.Cu, либо переходное + прямая на B.Cu/In2.Cu; проверка зазоров по геометрии (shapely).
3. `zero_len.py` — удаление нулевых и висящих сегментов и переходных, с сохранением пояска ≥ 0,125 мм. Запускать повторно, пока код возврата не 0.
4. `drc_fix.py` — удаление сегментов из нарушений зазора по отчёту DRC, чтобы `minirouter` проложил их заново.
5. `silk_place.py` — шелкография. Обозначения мелких пассивных (0603/0805) — только на F.Fab (сборочный чертёж), крупных — на F.Silkscreen.
6. `pcb_meta.py`, `pro_merge.py`, финальный DRC.

Что делать при остаточных нарушениях:

- Неразведённые цепи: сначала `ripnet.py` / `ripbox.py` (снять трассы цепи или области), затем `minirouter.py`.
- Нарушения зазоров: `drc_fix.py` + `minirouter.py`; если не сходится — изменить расстановку узла, а не ослаблять правила.
- Нарушения поясков: `zero_len.py`.

## Заливки и земля

- Заливки земли на F.Cu, In2 и B.Cu, сшивка переходными по сетке 2,5 мм там, где заливки всех слоёв совпадают (`stitch`).
- Все выводы GND микросхем — короткие стабы под корпус и переходные на In1.
- Перед DRC заливки перезаливаются (в GUI — `B`; в `kicad-cli pcb drc` — автоматически).

## Ворота фазы 6

```sh
kicad-cli pcb drc --schematic-parity --severity-all -o reports/DRC.rpt <project>.kicad_pcb
grep 'Found' reports/DRC.rpt
```

Ожидаемо: 0 нарушений, 0 неразведённых, 0 расхождений со схемой. Если DRC не использует настройки схемы (имена `D1A` вместо `D1.1`,
«net conflicts») — не хватает секции схемы в `.kicad_pro`: запусти `pro_merge.py`, затем DRC ещё раз (см. `gotchas.md`).

Отдельно проверь глазами, а не только DRC: ВЧ-трассы, питание DC/DC, тепловые полигоны, шелкографию на сборочном чертеже, ориентацию полярных элементов.
DRC не знает, что петля коммутации слишком длинная.
